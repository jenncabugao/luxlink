# LuxLink v0.1 — User Flows

## Vertical Slice A: Foster placement

1. Coordinator opens mobile app.
2. Taps "Create need."
3. Selects or creates animal.
4. Adds photo.
5. Selects type = Foster.
6. Adds timing and concise notes.
7. Publishes.
8. Matching eligible volunteers receive an alert.
9. Volunteer taps alert.
10. Volunteer sees animal + current need + timing + fit details.
11. Volunteer taps "I can help."
12. Volunteer enters availability and optional notes.
13. Offer appears in coordinator queue.
14. Coordinator taps offer.
15. Coordinator marks Contacted or Confirm.
16. On Confirm:
    - assignment created
    - need = Covered
    - volunteer notified
17. Coordinator sees prompt: "Share a thank-you with the community?"
18. Coordinator adds optional photo/copy and publishes recognition post.

## Vertical Slice B: Foster takeover

1. Current foster opens My Fosters.
2. Selects current animal.
3. Taps "Request coverage."
4. Selects start/end dates.
5. Adds optional note.
6. Request enters coordinator review.
7. Coordinator publishes request.
8. Eligible takeover volunteers receive alert.
9. Volunteer offers help.
10. Coordinator confirms.
11. Need = Covered.
12. Community thank-you optional.

## Vertical Slice C: Transport

1. Coordinator creates transport need.
2. Adds origin/destination and timing.
3. Eligible transport volunteers receive alert.
4. Volunteer offers help.
5. Coordinator confirms.
6. Need = Covered.
7. Community recognition optional.

## Vertical Slice D: Adoption-hours coverage

1. Current foster or coordinator creates adoption-hours need.
2. Adds pickup timing, adoption-hour window, return plan.
3. Eligible adoption-hours volunteers receive alert.
4. Volunteer offers.
5. Coordinator confirms.
6. Need = Covered.

## Vertical Slice E: Community volunteer ask

1. Coordinator creates volunteer need without animal.
2. Example: bag dog food Saturday 10–12.
3. Eligible volunteers receive alert.
4. Volunteers respond.
5. Coordinator marks request sufficiently staffed / closed.
6. Optional thank-you community post.

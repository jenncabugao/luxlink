# LuxLink Landing Page

This folder is ready for free hosting on GitHub Pages.

Files:
- index.html
- luxlink-logo.png

Fastest free publishing option:
1. Create a new public GitHub repository named `luxlink`.
2. Upload `index.html` and `luxlink-logo.png`.
3. In the repository, open Settings → Pages.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Choose the `main` branch and `/ (root)`.
6. Save. GitHub will give you a public URL such as `https://YOURUSERNAME.github.io/luxlink/`.

You can use that URL in LinkedIn until you buy a domain.

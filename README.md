Files:
- docs/product-spec.md
- docs/engineering-spec.md
- docs/user-flows.md

Recommended workflow:
1. Put these files into the LuxLink repo.
2. Ask Codex to read all specs first.
3. Start with only the Foster Placement vertical slice.
4. Review the proposed structure/schema before allowing implementation.
5. Expand to Takeover, Transport, Adoption Hours, and Volunteer requests only after the first slice works.
